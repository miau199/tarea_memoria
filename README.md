# Memoria SRAM Parametrizada en SystemVerilog

Este repositorio contiene la implementación y verificación en SystemVerilog de una estructura de memoria SRAM parametrizada como módulo `.top`, desarrollada para la clase de Arquitectura de Computadoras.

El diseño se basa en los principios arquitectónicos de almacenamiento por realimentación, celdas de memoria direccionables y control por buses (*Write Enable*, *Read Enable*, *Address Bus* y *Data Bus*).
